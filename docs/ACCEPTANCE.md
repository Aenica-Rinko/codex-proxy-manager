# v1.0 前本地验收记录

## v0.11.0 界面与隐私（2026-10-12，本地）

- 主面板采用固定导航、顶部启动/停止、完整节点工作区；增加独立隐私中心和截图模式。窗口模拟数据离屏渲染在 1100×780 与 1020×720 客户区检查；未运行用户真实管理会话进行桌面点击测试。
- 对照设计概念核对导航顺序、按钮分组、暗色配色、文字层级、节点表格和底部隐私入口；修复禁用按钮文字对比不足、隐私窗口底部说明截断、列表图像生命周期及排序框绘制问题。原生标题栏/控件语义、累计流量展示、无装饰导航图标是记录的实现差异；不宣称图像像素级完全一致。
- 日志采用固定事件类别，核心 info/debug 和未分类输出不写入文件，原始错误不落盘；启动后仅对本项目的本地核心请求 warning 级别。新日志约 1 MB 上限、一个备份、写入/启动触发 7 天轮转；旧日志不追溯脱敏。
- 日志清理只针对三份明确日志和各自 .1，活动会话禁用，链接路径拒绝。单元测试验证清理不触及其他文件或子目录。
- 单元测试验证截图模式隐藏节点/档案/应用、工具提示和搜索内容，刷新不泄漏，原始节点身份及切换仍保留；验证关闭后恢复正常显示。敏感弹窗/通知详情在截图模式下隐藏。
- Chrome 的产品代码隔离测试通过：有有效 STUN 基线，限制场景无 STUN UDP/host 候选且本地代理 HTTP 请求成功。无有效基线、存在观察到的 UDP/host、代理失败都不会判为通过。Codex/Electron 不支持此自动测试，保持未验证。
- PowerShell 7 完整回归、Windows PowerShell 5.1 离线单元与打包回归通过；核心启停/异常恢复、原始档案及 Windows Internet Settings 保持原检查结果。图形桌面点击工具缺少 node_repl 入口，采用原生离屏渲染与隔离控件测试；独立 Windows、高 DPI、多浏览器版本及公网泄漏验收未完成。
- 本轮未发布 GitHub Release，没有实现凭据加密或系统级防直连；Store/游戏变慢问题仍未修复。

## 本轮修复

档案管理的外部控制接口测试原来使用 UI 线程上的同步 WebClient 请求。现在在后台执行，并对每次连接/读取设置 2.5 秒超时。点击时固定输入，检查期间限制重复点击，窗口关闭后不更新已释放控件。只显示策略组数量或固定错误说明，不显示服务器原始错误。

检查只访问填写的本机控制接口，不保存档案、不切换节点。两次接口请求的超时分别计算；持续慢速发送响应的接口仍可能让后台工作持续更久，不应把单次读超时理解为整个检查的绝对时间上限。
