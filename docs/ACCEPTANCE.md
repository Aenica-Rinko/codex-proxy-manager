## 本轮修复

档案管理的外部控制接口测试原来使用 UI 线程上的同步 WebClient 请求。现在在后台执行，并对每次连接/读取设置 2.5 秒超时。点击时固定输入，检查期间限制重复点击，窗口关闭后不更新已释放控件。只显示策略组数量或固定错误说明，不显示服务器原始错误。

检查只访问填写的本机控制接口，不保存档案、不切换节点。两次接口请求的超时分别计算；持续慢速发送响应的接口仍可能让后台工作持续更久，不应把单次读超时理解为整个检查的绝对时间上限。
